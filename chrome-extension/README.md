# 选中文本 AI 助手（Chrome 插件）

功能：当你在网页中选中“段落或关键词”时，插件会在选区上方悬浮展示：

1. 解释（调用 Moonshot/Kimi API）
2. 翻译（调用 Moonshot/Kimi API，支持目标：中文/英文）
3. 朗读（调用浏览器内置 TTS，支持中文/英文朗读）
4. 润色（调用 Moonshot/Kimi API，结果可编辑，并提供“一键替换”回页面）

Moonshot/Kimi 文档：https://platform.moonshot.cn/docs

---

## 一、安装与部署（未打包方式）

1. 打开 Chrome，进入 `chrome://extensions/`
2. 打开右上角的 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择本仓库中的目录：`chrome-extension/`

加载成功后，你会在扩展列表看到插件“选中文本AI助手（解释/翻译/朗读/润色）”。

---

## 二、配置 Kimi API Key

1. 在扩展卡片里点击 **Options**（或打开该扩展的“详细信息/选项”）
2. 在页面里填入：
   - `Kimi API Key`
   - `model`（默认 `kimi-k2.5`）
3. 点击 **保存配置**

插件会在后台（service worker）读取配置，并通过 Moonshot/Kimi API 完成“解释/翻译/润色”。

> 说明：朗读使用浏览器内置语音引擎，不需要 API Key。

---

## 三、使用方法

1. 打开任意网页
2. 用鼠标选中一段文本或关键词
3. 选区上方会出现悬浮面板（按钮顺序：解释 -> 翻译 -> 朗读 -> 润色）
4. 点击：
   - **解释**：结果显示在面板下方“解释结果”
   - **翻译**：选择目标语言后点击，结果显示在“翻译结果”
   - **朗读**：朗读你当前选中的原文
   - **润色**：结果显示在“润色结果（可编辑）”里；你可以修改文本，然后点击“一键替换”，将替换回页面选中的内容

---

## 四、接口与实现说明

- Kimi Chat Completions 请求地址（默认）：`https://api.moonshot.cn/v1/chat/completions`
- 请求体为 OpenAI 兼容的 `chat.completions.create` 风格：
  - `messages`：system + user
  - `model`：Options 里配置的模型
- 内容脚本只负责 UI/选区捕获与朗读；Kimi 调用在 `background.js` 中完成，避免直接在内容脚本暴露 Key。

---

## 五、注意事项 / 限制

- “一键替换”基于当前选区的 `Range` 进行替换：对于跨复杂 DOM 结构的选择，可能无法完美保留原始格式。
- 为了控制成本与速度，插件会对选中内容做最大长度截断（默认 2000 字符）后再发送给 Kimi。
  - 如果选区过长（已发生截断），润色结果仍可查看/编辑，但“一键替换”会被禁用，以避免替换错位造成内容丢失。
